# AI Import Cost Calculator — FOB

Практический AI-калькулятор для расчёта импортной себестоимости товара на условиях FOB с использованием **ChatGPT и Excel**.

Инструмент обрабатывает исходные данные, учитывает ставки логистической компании, таможенные платежи и дополнительные расходы. Результат — готовый Excel-калькулятор с итоговой ценой входа товара и краткий расчётный бриф.

## Возможности

- Перенос исходных данных в установленный Excel-шаблон с сохранением формул и оформления.
- Расчёт количества коробок, объёма, массы партии, стоимости инвойса и таможенных платежей.
- Проверка актуального таможенного сбора по доступным нормативным источникам.
- Расчёт итоговой себестоимости за штуку в USD и RUB.
- Автоматическое формирование итогового Excel-файла и краткого брифа.

Текущая версия рассчитана на **USD/шт, условия FOB и заранее полученные логистические ставки**. Расходы задаются для конкретной партии без распределения стоимости полного контейнера по объёму или массе.

## Файлы проекта

### Prompts, Logic and Training

Папка содержит инструкцию для ChatGPT и два эталонных Excel-файла:

- **Промт_ИМПОРТНЫЙ КАЛЬКУЛЯТОР — USD_ШТ.docx** — логика работы, правила переноса данных, проверки расчётов и сохранения оформления.
- **USD_ШТ_ВВОДНЫЕ_Листья искусственной пальмы_СТАВКА.xlsx** — пример исходных данных.
- **РАСЧЕТ_USD_ШТ_Листья искусственной пальмы_СТАВКА.xlsx** — готовый расчётный шаблон с формулами.

### Test Data and Results

Папка содержит контрольный пример на другом товаре:

- **USD_ШТ_ВВОДНЫЕ_Утюги_СТАВКА.xlsx** — тестовые исходные данные.
- **РАСЧЕТ_USD_ШТ_Утюги_СТАВКА.xlsx** — результат обработки для сравнения.

## Как начать работу

1. **Настройте ChatGPT.** Создайте отдельный чат или проект. Вставьте текст инструкции и приложите два Excel-файла из папки **Prompts, Logic and Training**. Выполните первоначальный запуск.
2. **Проверьте расчёт.** В том же чате загрузите файл вводных по утюгам из папки **Test Data and Results**. Получите новый Excel и сравните его с контрольным результатом.
3. **Используйте для собственных расчётов.** Заполните входной Excel по установленному образцу и загрузите его в настроенную ветку. ChatGPT сформирует расчёт по доступному шаблону.

Для работы необходимы возможности ChatGPT по обработке Excel и доступ к актуальным источникам для проверки таможенного сбора. Настройка по образцам не является дообучением самой AI-модели.

Расчёт носит предварительный характер и не является сертифицированным способом определения таможенной стоимости или официальным таможенным заключением.

Перед практическим применением необходимо проверить ставки, условия поставки, состав таможенной стоимости, логистические расходы и итоговую арифметику.

Данные опубликованных примеров используются для иллюстрации работы инструмента и не являются действующими коммерческими предложениями.
